# Five-store-owner usability study

Status: **not conducted**. The owner must arrange five real store owners with varied software experience. No participants, outcomes, timings or customer activity have been invented.

Run against a test environment with test inventory and test payments. Use both a desktop and a phone across the group. Disable optional measurement or exclude the study browsers; record observations in this document using participant codes rather than names. Obtain permission for any recording. Screenshots must omit private addresses, bank details, customer information and sign-in links.

Ask each participant to do the following without a tour:

1. Starting signed out, find Sell and explain fees, the listing process and payout timing.
2. Open the prepared seller account, identify the four setup tasks, save a partial step, leave and return.
3. Publish a real test model with suitable photos, or identify the exact block preventing publication.
4. Download the inventory template, preview a file containing a correct row and an invalid row, correct the error, and save. Repeat the same SKU with a changed quantity and check that no duplicate appears.
5. Change stock after a sale on another website.
6. Find Orders, identify the ship-by deadline, and add test tracking or explain the next action. Find Payments and explain eligibility versus bank arrival.

Observe before helping. Start timing when the participant begins each task. Record success, partial success or failure; time in seconds; any assistance; wrong turns; and the participant's explanation. If help becomes necessary, record the point and exact prompt. Do not count assisted completion as unassisted success.
